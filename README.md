# Daywell — Daily Homework Planner

A small, responsive homework planner based on a daily schedule template. Add homework by subject, choose a study time and estimate, then track what is finished for each day.

## Features

- Daily homework list with all, to-do, and finished filters
- Subject, planned time, estimated duration, and importance for each task
- A day schedule and summary of planned study time
- Daily completion progress
- Saves each day in this browser using local storage
- No account or server required

## Open

Open `index.html` in a current web browser. Your entries stay in that browser on that device. Clearing browser site data removes saved entries.
